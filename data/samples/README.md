# Sample results files (synthetic)

Generated by `python -m canary samples` from the traffic simulator: outcomes are drawn from a known truth, call durations are resampled from the 713 real recordings. They prove the engine reads files and decides correctly; they say nothing about a real prompt.

| File | Truth injected | Expected decision |
|---|---|---|
| results_b_wins.csv | B truly +7 points | expected PROMOTE |
| results_b_harmful.csv | B truly -10 points | expected STOP_HARM |
| results_b_flat.csv | A and B identical | expected INCONCLUSIVE with a 'more leads needed' answer |
| results_guardrail_hold.csv | B +7 points but 20% longer calls | expected HOLD_FOR_APPROVAL |
| results_early_hangup.csv | B +7 points but 6 points more calls under 15 s | expected a stop on the hang-up guardrail (run with guard_below_s=15) |
| results_messy.csv | B truly +7 points, but a messy export (duplicates, other variant names, leads served both prompts, unknown variants) | expected PROMOTE, with the data notes listing what was found |
| daily_b_wins.csv | the same results as 'B wins', as a daily summary | PROMOTE |

Try: `python -m canary decide data/samples/results_b_wins.csv --goal buylead_created --share-b 0.3 --baseline 0.45 --mde 0.07 --window-days 14`
